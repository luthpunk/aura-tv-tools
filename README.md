# Aura TV Tools (`com.gathin.auratvtools`)

Aplikasi Android (HP) All-in-One seperti **atvTools** + **Live Touch Screen Mirroring** untuk mengendalikan, memantau, menginstal APK, dan me-mirror layar **STB / Android TV** langsung ke layar HP melalui jaringan Wi-Fi (**Wireless ADB Port 5555**).

## ✨ Fitur Utama
1. **📺 Live Screen Mirroring + Layar Sentuh Langsung (`MirrorActivity`)**
   - Streaming layar STB secara real-time (**H.264 60fps Hardware Decoder**) langsung ke layar HP tanpa perlu menginstal aplikasi tambahan di STB.
   - **Touch, Swipe & Long-Press Langsung:** Ketuk, geser, dan tahan di layar HP untuk mengontrol kursor/aplikasi di STB secara akurat (cocok untuk aplikasi non-TV yang butuh sentuhan/mouse).
   - Pilihan kualitas **720p Smooth (4 Mbps)**, **1080p HD (8 Mbps)**, dan **Mode Kompatibel**.
2. **🔍 Koneksi Cepat & Auto-Scan Wi-Fi (`AdbClient`)**
   - Pemindai subnet otomatis (~2 detik) untuk menemukan semua perangkat STB / Android TV dengan port `5555` terbuka di jaringan Wi-Fi yang sama.
3. **📦 Sideload Install APK 1-Klik & App Manager**
   - Pilih file `.apk` dari penyimpanan HP dan langsung kirim + instal ke STB lengkap dengan indikator persentase progres.
   - Kelola aplikasi STB: **Buka di TV**, **Force Stop**, **Hapus Data/Cache**, dan **Uninstall**.
4. **🎮 Remote D-Pad, Media & Keyboard Langsung**
   - Navigasi D-Pad lengkap dengan umpan balik getar (haptic), kontrol volume/media, serta input teks langsung dari keyboard HP ke layar TV.
5. **📊 Monitor Sistem & Terminal Shell ADB**
   - Pantau Model STB, Versi Android, Resolusi, penggunaan RAM, Penyimpanan Internal, dan Suhu CPU STB, serta jalankan perintah shell ADB kustom.
